# Conclusión
El uso de Airflow como nuestra única herramienta de “tracking” y orquestación nos permitió mantener un registro preciso de cada ejecución: desde la extracción y limpieza de datos hasta el entrenamiento incremental en ventanas de semanas. Al versionar el código y los artefactos (merged, labeled, features, modelo serializado) en Git y en nuestro sistema de ficheros, pudimos reproducir cada experimento, comparar parámetros y revertir cambios sin depender de plataformas externas como MLflow. Esta trazabilidad integrada agilizó la identificación de errores y la validación de mejoras, porque bastaba con revisar los logs y las rutas XCom en la UI de Airflow para entender exactamente qué se había producido en cada DAG run.
